Question-
How do the four pillars of OOP—Inheritance, Polymorphism, Abstraction, and Encapsulation—help manage logic and reduce complexity in large-scale TypeScript projects?

Answer-
Object-Oriented Programming (OOP) has four main pillars: Inheritance, Polymorphism, Abstraction, and Encapsulation. These pillars help manage logic, improve code organization, and reduce complexity in large-scale TypeScript projects.

1. Inheritance

Inheritance allows one class (child class) to inherit properties and methods from another class (parent class).
This helps reduce code duplication and improves reusability.

<!-- Example for Inheritance -->
class Animal {
  sound() {
    console.log("Animal makes sound");
  }
}

class Dog extends Animal {}

Here, Dog inherits the sound() method from Animal.

2. Polymorphism

Polymorphism allows the same method to behave differently depending on the object or class.

<!-- Example for Polymorphism -->
class Animal {
  sound() {
    console.log("Animal sound");
  }
}

class Dog extends Animal {
  sound() {
    console.log("Bark");
  }
}

Here, the sound() method behaves differently in the Dog class.

3. Abstraction

Abstraction hides unnecessary implementation details and shows only essential features.It helps developers focus on what an object does instead of how it works.In TypeScript, abstraction is commonly achieved using abstract classes and methods.

<!-- Example for Abstraction -->
abstract class Payment {
  abstract pay(): void;
}


4. Encapsulation

Encapsulation means protecting data by restricting direct access to it using private, protected, or public access modifiers.

<!-- Example for Encapsulation -->
class User {
  private password = "12345";
}

Here, the password cannot be accessed directly from outside the class.

Together, these four pillars helps us with reduce code complexity, improve maintainability, increase code reusabilitymake large-scale TypeScript applications easier to manage and scale
