Question-
How do Pick and Omit utility types prevent code duplication while creating specialized "slices" of a master interface? Discuss how this keeps your code DRY (Don't Repeat Yourself).


Answer:-
In TypeScript, Pick and Omit utility types help keep code DRY (Don't Repeat Yourself) by creating specialized versions of a master interface without rewriting the same properties again and again.

1. Pick<Type, Keys> 
            -creates a new type by selecting only specific properties from an existing interface.
2. Omit<Type, Keys> 
            creates a new type by removing specific properties from an existing interface.

This approach reduces code duplication, improves maintainability, and keeps all related types connected to a single source of truth.

Example
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}

Using Pick:

type UserProfile = Pick<User, "name" | "email">;

Here, UserProfile contains only name and email.

Using Omit:

type PublicUser = Omit<User, "password">;

Here, PublicUser contains all properties except password.

Instead of creating multiple similar interfaces manually, Pick and Omit allow us to generate reusable “slices” from one master interface. This keeps the code cleaner, more scalable, and easier to update.
